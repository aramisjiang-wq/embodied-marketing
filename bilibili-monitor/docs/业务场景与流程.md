## 3. 详细业务场景

### 3.1 场景一：日常数据监控

**场景描述**：市场人员每天上班后打开系统，快速了解竞品最新数据状态

**触发条件**：每日上班

**用户流程**：
```
1. 打开Dashboard
   ├── 查看汇总指标 (品牌数/视频数/播放量/粉丝)
   ├── 查看品牌排行 (按播放量排序)
   └── 查看更新时间

2. 扫描异常数据
   ├── 播放量异常高的品牌
   ├── 新发布视频的品牌
   └── 粉丝数变化明显的品牌

3. 点击进入详情
   └── 对可疑数据进行深入分析
```

**系统响应**：
- Dashboard加载时间 < 3秒
- 突出显示较上日变化 > 10% 的数据
- 显示数据更新时间

**输出**：
- 发现1-2个需要关注的品牌/视频
- 记录到工作笔记

---

### 3.2 场景二：周会数据准备

**场景描述**：团队负责人准备周会汇报材料，需要对比本周vs上周数据

**触发条件**：每周五下午

**用户流程**：
```
1. 选择时间范围
   └── 选择"上周" (如: 4月21日 - 4月27日)

2. 查看竞品对比
   ├── 选择要对比的品牌 (如: 宇树/银河通用/越疆)
   └── 查看播放量/发布量对比

3. 制作趋势图
   ├── 生成周趋势折线图
   └── 保存为图片

4. 导出数据
   ├── 导出Excel包含:
   │   ├── 各品牌汇总数据
   │   ├── 各品牌视频明细
   │   └── 数据来源说明
   └── 用于PPT制作

5. 整理要点
   ├── 本周竞品声量排名
   ├── 竞品内容策略变化
   └── 下周关注建议
```

**系统响应**：
- 支持自定义日期范围选择
- 支持最多5个品牌同时对比
- 图表支持下载为PNG
- Excel导出包含原始数据和汇总

**输出**：
- 周会数据图表 (图片)
- 周会数据表格 (Excel)
- 周会要点总结

---

### 3.3 场景三：月度复盘分析

**场景描述**：市场总监进行月度数据复盘，分析整体趋势

**触发条件**：每月最后一天/次月第一天

**用户流程**：
```
1. 选择时间范围
   └── 选择"本月" (如: 2026年4月)

2. 查看月度总览
   ├── 总播放量 vs 上月
   ├── 总发布量 vs 上月
   ├── 粉丝净增 vs 上月
   └── 行业排名变化

3. 分析品牌表现
   ├── 各品牌月度数据表格
   ├── 排名变化分析
   └── 重点品牌深度分析

4. 内容策略分析
   ├── 发布频率变化
   ├── 内容类型趋势
   └── 爆款视频分析

5. 生成月报
   ├── 一键生成月报模板
   ├── 包含图表和数据
   └── 导出PDF
```

**系统响应**：
- 月度数据聚合计算
- 同比/环比数据计算
- 月报模板支持自定义

**输出**：
- 月度数据报告 (PDF/PPT)
- 重点关注品牌清单
- 下月竞品监控建议

### 3.4 场景四：发现异常波动

**场景描述**：系统发现竞品数据异常，触发告警

**触发条件**：
- 单视频播放量日增 > 50%
- 单品牌粉丝日增 > 20%
- 竞品发布重磅视频

**用户流程**：
```
1. 收到告警通知
   └── "宇树科技视频播放量单日 +120%"

2. 查看详情
   ├── 点击查看该视频
   └── 分析原因

3. 记录分析
   ├── 视频内容分析
   ├── 可能原因:
   │   ├── 视频上了热门
   │   ├── 被大V转发
   │   └── 内容刚好蹭上热点
   └── 对我司的启示

4. 采取行动 (如需要)
   ├── 通知内容团队参考
   └── 调整投放计划
```

**系统响应**：
- 播放量对比昨日数据
- 计算涨幅百分比
- 支持按涨幅排序

**输出**：
- 异常记录
- 分析结论
- 行动建议

---

### 3.5 场景五：品牌管理

**场景描述**：添加新竞品或删除不需要监控的品牌

**触发条件**：业务需求变化

**添加品牌流程**：
```
1. 点击"添加品牌"
   └── 输入B站账号MID或主页链接

2. 系统验证
   ├── 调用B站API获取账号信息
   ├── 显示账号名称和头像预览
   └── 确认添加

3. 首次数据采集
   ├── 获取账号基础信息
   ├── 采集历史动态
   └── 采集历史视频数据

4. 完成
   └── 新品牌出现在列表中
```

**删除品牌流程**：
```
1. 选择要删除的品牌
   └── 确认删除操作

2. 系统提示
   └── "删除将同时删除所有关联数据"

3. 确认删除
   └── 删除品牌、视频、统计数据

4. 完成
   └── 品牌从列表消失
```

## 5. 关键决策点

### 5.1 数据采集决策

| 决策点 | 选项 | 建议 |
|--------|------|------|
| 更新频率 | 每小时/每6小时/每日 | 每6小时 (平衡vs风险) |
| 历史数据 | 最近1年/2年/全部 | 最近2年 |

## 6. 风险与应对

### 6.1 技术风险

| 风险 | 影响 | 应对 |
|------|------|------|
| B站接口变更 | 数据采集失败 | 定期检查和更新脚本 |
| IP被封禁 | 无法采集 | 使用代理IP池 |
| 数据库过大 | 查询变慢 | 定期清理和优化 |

### 6.2 业务风险

| 风险 | 影响 | 应对 |
|------|------|------|
| 品牌账号错误 | 数据不准确 | 人工确认账号 |
| 数据延迟 | 决策失误 | 显示数据更新时间 |
| 监控遗漏 | 错过竞品动作 | 定期检查账号列表 |
