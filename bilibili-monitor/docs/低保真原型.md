### 4.2 数据操作

| 操作 | 触发 | 结果 |
|------|------|------|
| 点击品牌卡片 | 单击 | 跳转品牌详情 |
| 点击添加品牌 | 单击 | 打开添加弹窗 |
| 点击刷新 | 单击 | 触发数据采集 |
| 点击导出 | 单击 | 下载Excel |
| 点击删除 | 单击 | 确认后删除 |
| 选择日期范围 | 选择 | 刷新图表数据 |

| 场景 | 加载状态 |

| 数据刷新 | 卡片顶部loading条 |
| 弹窗打开 | 内容区loading |
| 导出中 | 按钮显示spinner |
