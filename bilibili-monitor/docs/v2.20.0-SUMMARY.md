## 📝 使用快速参考

### 开发者（macOS）

```bash
# 查看当前状态
cat scripts/collect_status.json | jq '{is_running, last_run_summary}'

# 手动运行采集
cd scripts && python collect.py

# 启用定时任务（可选）
cp scripts/com.bilibili-monitor.daily-collect.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.bilibili-monitor.daily-collect.plist
```

### 运维人员（Linux服务器）

```bash
# 一键部署
sudo ./scripts/deploy-to-server.sh

# 或手动部署（参考 docs/DEPLOYMENT.md）

# 常用命令
sudo systemctl status bilibili-monitor      # 查看状态
sudo journalctl -u bilibili-monitor -f       # 实时日志
sudo systemctl restart bilibili-monitor     # 手动触发
sudo systemctl start bilibili-monitor.timer # 启用定时器
```

### 产品经理/测试

```bash

3. 底部显示 "上次更新: 5/8 15:47"
4. 本周发布视频在厂家对比上方
```
